# Exercises: knn classification

1. Solve the mathematical fixture by hand and explain the influence of each parameter.
2. Compare a constant-feature dataset and a variable-feature dataset. Explain any undefined statistic.
3. Compare training and validation scores across the configured parameter grid. Explain underfitting and overfitting using evidence.
4. Change the training seed without inspecting holdout predictions during selection. Compare uncertainty across runs.
5. Reload the saved model in a fresh process and confirm the same predictions.
6. Identify a data-quality issue in eda/findings.md and propose an improvement that can be evaluated using training CV.

A successful answer contains the calculation, a reproducible command, the relevant artifact, and a reasoned interpretation; a higher score alone is insufficient.
